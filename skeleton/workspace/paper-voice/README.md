# paper-voice

Optional. Put examples of writing you want this paper to sound like here —
past papers of your own (full PDFs are fine), or freeform notes on style,
register or convention ("UK spelling", "short paragraphs", "avoid the passive
where the active reads as well").

Nothing here is read automatically. Run `/paper-voice` whenever you want it
analysed — at the start of the project, or any time later, including after
adding something new. It distills whatever is in this directory into
`paper/voice.md`, which is what `/paper-draft` and `/paper-frame` actually
consult from then on.

This directory is never touched by anything else in sci-paper, and it never
needs to be emptied or tidied — the raw material stays here for as long as
you want it to.
